# EdSpec AI POC Scope

## In scope

1. EdTech specification
2. Specification versioning
3. Specification approval
4. Assessment generation
5. Independent assessment review
6. Deterministic validation
7. Human approval
8. Audit trail
9. Basic React dashboard

## Out of scope

- LMS
- Grading
- Student simulation
- RAG
- Vector database
- Audio or video
- Accessibility testing
- Automatic publishing
- Non-MCQ assessment formats

## POC scenario

End users can create specifications for different subjects or topics. The POC assessment format remains MCQ-based so deterministic validation, review, and audit stay simple.
